
# Аналізатор мережевих журналів на Python

Навчальний екзаменаційний проєкт із Python. Консольна програма читає журнал підключень до сервера, перевіряє записи, обчислює статистику та зберігає звіт.

## Можливості

- Читання журналу з файлу `network_log.txt`.
- Перевірка кількості полів, статусу підключення та номера порту.
- Окремий підрахунок некоректних записів.
- Підрахунок успішних і невдалих підключень та відсотка невдач.
- Визначення IP з найбільшою кількістю невдалих спроб.
- Визначення найпопулярнішого порту.
- Пошук IP із трьома або більше невдалими підключеннями.
- Збереження результатів у `report.txt` за вибором користувача.
- Обробка помилок читання, запису та неправильного вибору меню.

## Файли проєкту

| Файл | Призначення |
|---|---|
| `main.py` | Код програми та консольне меню |
| `network_log.txt` | Тестовий журнал: 7 коректних і 4 некоректні записи |
| `report.txt` | Приклад сформованого звіту |
| `.gitignore` | Виключення службових файлів із Git |

## Запуск

Потрібен Python 3.6 або новіший. Додаткові бібліотеки не потрібні.

1. Завантажте репозиторій через **Code → Download ZIP** і розпакуйте архів.
2. Відкрийте термінал у папці, де знаходяться `main.py` і `network_log.txt`.
3. Запустіть:

```bash
python main.py
```

У Windows також можна використати:

```bash
py main.py
```

Програму потрібно запускати з папки проєкту, оскільки шляхи до журналу та звіту відносні.

## Меню

```text
===== АНАЛІЗАТОР МЕРЕЖЕВИХ ЖУРНАЛІВ =====
1. Проаналізувати журнал
2. Показати статистику
3. Показати підозрілі IP-адреси
4. Зберегти звіт
0. Вихід
```

Спочатку виберіть `1`, щоб проаналізувати журнал. Потім можна переглянути статистику, підозрілі адреси або зберегти звіт.

Після зміни журналу повторно виберіть `1`. Кожен аналіз починає підрахунок заново.

## Формат журналу

Кожен запис містить чотири поля, розділені крапкою з комою:

```text
дата та час;IP-адреса;статус;порт
```

Приклад:

```text
2026-10-18 08:15:10;192.168.1.10;SUCCESS;22
```

Допустимі статуси: `SUCCESS` і `FAILED`. Порт має бути цілим числом від `1` до `65535`.

У тестовому файлі останні чотири рядки навмисно містять помилки:

| Помилка | Приклад |
|---|---|
| Недостатня кількість полів | Відсутній порт |
| Неприпустимий статус | `ERROR` |
| Порт не є цілим числом | `abc` |
| Порт поза допустимим діапазоном | `70000` |

Ці записи враховуються як некоректні та не впливають на статистику підключень.

## Звіт

Пункт `4` створює або перезаписує `report.txt`.

Звіт містить дату й час формування, статистику останнього аналізу, найактивніший IP за кількістю невдач, найпопулярніший порт і перелік підозрілих адрес.

Доданий до репозиторію `report.txt` є прикладом результату роботи.

## Структура програми

| Функція | Призначення |
|---|---|
| `analyze_log()` | Читання, перевірка записів і розрахунок результатів |
| `show_statistics()` | Виведення статистики |
| `show_suspicious_ips()` | Виведення підозрілих адрес |
| `save_report()` | Запис звіту |

У проєкті використано функції, цикли, умовні оператори, словники, роботу з файлами та обробку винятків.

## Межі навчального прикладу

Поріг із трьох невдалих спроб — навчальна евристика, а не підтвердження атаки. Спроби підраховуються за весь файл, без часового вікна.

Програма перевіряє кількість полів, статус і порт. Формат IP-адреси та дати окремо не перевіряється.

Якщо кілька IP або портів мають однаковий максимальний лічильник, обирається перший зустрінутий.
